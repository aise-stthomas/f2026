**1.** A forty-page policy holds the answer to "Can I expense a monitor for my home
office? I'm in Berlin" in one sentence of section 4.2, with an exception for Germany in
section 4.3. The model can be handed about eight passages. Which unit of retrieval does
the lecture choose, and why?

- (a) The whole document, since the answer is certainly somewhere inside it.
- (b) The sentence, since it is the smallest unit that contains the answer.
- (c) A fixed window of 200 words, since equal sizes keep the index simple.
- (d) A chunk cut on the document's own structure, capped in size, with the heading path
  prepended and a rule kept with its exception, carrying the document version and the
  as-of as metadata; the sentence alone loses the Germany exception, and the document
  alone buries it among 25,000 tokens.

**2.** The chunk that answers "Can I expense a monitor for my home office?" says
"display," not "monitor," and is missed by the lexical index. A second question asks
about "ERR-4032" and the vector index returns plausible neighbours that do not contain
the code. What does the lecture's design do about both?

- (a) Run both indexes under the same filter, merge the two lists by rank rather than
  by score, and let a reranker read the question against each candidate together; the
  lexical index is exact and literal, the vector index handles paraphrase, and neither
  alone is enough.
- (b) Use the vector index only and add synonyms for every error code to the embedding
  model's vocabulary.
- (c) Use the lexical index only and rewrite every question with a model before
  searching.
- (d) Raise the number of candidates each index returns until both chunks appear.

**3.** The policy assistant's context now holds, besides the instructions and the eight
passages, a few worked answers in the required form and a briefing written by a model
every ten minutes. According to the lecture, what do the examples and the briefing have
in common?

- (a) Both are generated by the language model at the request, so neither needs a
  version.
- (b) Both are artifacts built before the request, each with a version and an as-of,
  each measured by the harness, and each changed only through a release; the examples
  are a dataset whose effect shows in the format and NOT_FOUND rates, and the briefing
  is judged for groundedness against the sources it cites.
- (c) Both are part of the model's weights after fine-tuning.
- (d) Both are kept in the prompt string and edited by hand when an answer is wrong.

**4.** The freshness ladder on the lecture's slide ends in one rule. An employee's
remaining leave balance changes by the minute; the display policy changes monthly;
"what changed this week" is summarized every ten minutes. Which placement follows from
the rule?

- (a) All three are embedded and indexed, with the index rebuilt every minute.
- (b) The balance is embedded hourly, the policy is looked up, and the summary is
  written by the model at each request.
- (c) The policy is indexed on the schedule, the summary is a precomputed briefing with
  its as-of, and the balance is looked up at the request from the system of record and
  never enters the index, because what changes faster than the index is rebuilt is
  never in the index.
- (d) All three are placed in the prompt verbatim at every request, since the context
  window is large enough.

**5.** In the studio, a team's design indexes the airline's waivers within minutes of
publication and deletes a withdrawn waiver's chunk in the same run. The one question
asks about a passenger told at 19:40 that a hotel was covered, by a waiver withdrawn at
19:30. According to the answer key, which component should have stopped the answer,
and what does the log have to hold for the team to know what happened?

- (a) The embedding model, by re-embedding the question; the log holds the final
  answer.
- (b) The reranker, by lowering the withdrawn chunk's score; the log holds the
  passenger's booking.
- (c) The check-and-quote stage, by re-reading the quoted waiver's status at the moment
  of the answer rather than trusting the chunk's copy; the log holds the whole context
  with the index version, the briefing version, the status minute and the quoted
  waiver's version and expiry.
- (d) The API gateway, by throttling questions during a disruption; the log holds the
  request count.

**6.** *(Reading)* Lewis et al. describe retrieval-augmented generation as combining
two kinds of memory. Which statement matches the paper?

- (a) Parametric memory, the knowledge in a pre-trained sequence-to-sequence model's
  weights, and non-parametric memory, a dense vector index of Wikipedia accessed by a
  pre-trained neural retriever; the retrieved passages condition the generator, and the
  index can be updated without retraining the model.
- (b) Short-term memory, the current prompt, and long-term memory, a database of past
  conversations the model consults by keyword.
- (c) A lexical index for exact terms and a vector index for paraphrase, fused by rank.
- (d) The model's context window and a cache of its previous answers.

**7.** *(Reading)* Which of these is among the judge limitations Zheng et al. name, and
what is the paper's own test for it?

- (a) Recency bias, tested by re-asking the judge a day later.
- (b) Position bias, a preference for one position in a pair regardless of content,
  tested by swapping the order of the two answers and checking whether the verdict is
  consistent.
- (c) Vocabulary bias, tested by replacing rare words with common ones.
- (d) Citation bias, tested by removing the citations from both answers.

**8.** *(Reading)* Manning, Raghavan and Schütze introduce the inverted index in
chapter 1. Which description matches the structure as the book defines it?

- (a) A table of documents, each listing the terms it contains in order of appearance,
  scanned for each query.
- (b) A matrix with one row per term and one column per document, stored in full.
- (c) A hash from document id to a fixed-length vector.
- (d) A dictionary of terms, each pointing to a postings list of the documents that
  contain the term, with the postings sorted by document id so that lists can be
  intersected in one pass.

**9.** *(Lab)* On the runbook corpus, the lexical retriever wins the identifier slice,
the vector retriever wins the paraphrase slice, and hybrid comes out between them on
both rather than above both. The lab points at one place in the code for why. What is
the explanation, and what in the lecture's design addresses it?

- (a) Reciprocal rank fusion merges the two lists by rank, so the weaker list's noise is
  weighted equally with the stronger list's hits; the lecture's design has a reranker
  after the merge that reads the question against each candidate, and the lab does not.
- (b) The embeddings were truncated to 768 dimensions, which breaks hybrid search.
- (c) The lexical index was built without stop words, so hybrid double-counts them.
- (d) Hybrid search always underperforms the better single retriever by construction.

**10.** *(Lab)* Eight hand-written answers are seeded into the set the judge scores,
four of them wrong on purpose, before you label them and validate the judge against
your labels. Why does the lab do this?

- (a) To make the labelling take longer so that agreement between partners can be
  measured.
- (b) To test whether the deployed service is faster than the local one.
- (c) Because sensitivity is measured on real failures, and the system's own answers
  may contain few or none; a judge that has never been shown a failure has never been
  tested, and the seeded misses, including a dropped condition, are the slice that
  measures it.
- (d) To check that the embedding cache is being used.
